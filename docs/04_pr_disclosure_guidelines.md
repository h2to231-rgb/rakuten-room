# PR表記・コンプライアンスガイドライン

景品表示法のステルスマーケティング規制（2023年10月施行）と、優良誤認・有利誤認表示の禁止に対応するための
投稿ルール。ライティングAgentが生成する全ての下書きは、投稿前に必ずこのルールでチェックする
（[compliance/pr_checker.py](../compliance/pr_checker.py)で自動チェック可能）。

## 1. PR表記の基本ルール
- 投稿本文の**冒頭または末尾の目立つ位置**に、広告である旨を明記する（大量のハッシュタグの中に埋もれさせない）
- 使用する定型文（いずれかを必ず含める）:
  ```
  【PR】本投稿には楽天アフィリエイトリンクを含みます。商品購入により紹介料を得ることがあります。
  ```
  ```
  ※アフィリエイトリンクを含みます（本投稿経由の購入で報酬が発生する場合があります）
  ```
- 「#PR」「[PR]」だけを他のハッシュタグに紛れ込ませるのはNG。文章内に自然文で明示する。

## 2. 優良誤認（効果・効能の誇大表現）の禁止
| NG例 | 理由 | OK例 |
|---|---|---|
| 「絶対に痩せる」「必ず改善する」 | 断定的な効果保証 | 「私が使ってみた感想では〜でした（個人の感想です）」 |
| 「医学的に証明された効果」 | 根拠なき医学的主張 | 「メーカー公式サイトによると〜という成分が含まれています」 |
| 「たった3日で効果を実感」 | 個人差を無視した断定 | 「1週間使ってみて自分は〜と感じました」 |
| 「副作用なし・100%安全」 | 断定的な安全性主張 | （安全性の断定はしない。気になる場合は公式情報へのリンクに留める） |

## 3. 有利誤認（価格・取引条件の誇大表現）の禁止
| NG例 | 理由 | OK例 |
|---|---|---|
| 「今だけ半額」（常時同価格の場合） | 事実と異なる期間限定表示 | 実際に確認できた価格・セール情報のみ記載 |
| 「業界No.1」「売上日本一」（出典なし） | 根拠のない優良誤認表示 | 出典を明記する場合のみ使用可（例: 「楽天市場コスメジャンル週間ランキング1位（2026年8月時点、楽天市場調べ）」） |
| 「在庫残りわずか」（実際の在庫状況不明） | 事実確認できない煽り文句 | 商品ページの実際の表示のみ引用 |

## 4. 投稿前チェックリスト（人間の最終確認用）
- [ ] PR表記が本文中に自然な形で入っている
- [ ] 効果・効能について断定表現を使っていない（「個人の感想」であることが明確）
- [ ] 価格・キャンペーン情報は商品ページの実際の表示と一致している
- [ ] No.1表現などを使う場合、出典・調査時点を明記している
- [ ] `compliance/pr_checker.py` の自動チェックで指摘なし、または指摘内容を確認済み

## 5. 自動チェックツール
```bash
python compliance/pr_checker.py content_drafts/2026-08-24_beauty.txt
```
PR表記の有無と、NGフレーズへの該当を検出する（完全ではないため、最終判断は人間が行うこと）。
