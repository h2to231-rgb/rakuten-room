# ジャンル横断テスト計画

ジャンルを最初から一つに絞らず、6週間・毎日1投稿ペースで3ジャンルをローテーションしながら反応を見て、
7週目以降にデータに基づいて注力ジャンルを1〜2個に絞り込む。

## テスト対象ジャンル（候補3つ）

| ジャンル | 選定理由 | 想定リスク |
|---|---|---|
| ガジェット・家電 | 単価が比較的高く、成果報酬額が伸びやすい。トレンドサイクルが速くリサーチAgent（RWS ランキングAPI等）と相性が良い | 競合が多く、専門知識が浅いと差別化しづらい |
| コスメ・美容 | ROOM全体でエンゲージメント（いいね・フォロー）が付きやすいジャンル。ストーリー性のある紹介文が刺さりやすい | 景品表示法（優良誤認・効能効果の誇大表現）に最も敏感な領域。コンプラAgentのチェックを厳格にする必要あり |
| キッチン・生活雑貨 | 単価は中程度だが季節企画（お弁当グッズ、収納等）でまとめ投稿が作りやすく、リピート閲覧されやすい | 単体の商品では地味になりがちで、企画力（テーマ設定）に成果が依存する |

初期プロフィールは3ジャンルとも扱えるよう汎用的なトンマナにしておき（[01_account_setup_checklist.md](01_account_setup_checklist.md)参照）、
投稿ごとにハッシュタグ/カテゴリで分類してテスト後に比較できるようにする。

## ローテーション例（1週間サイクル、毎日1投稿）
- 月・木: ガジェット・家電
- 火・金: コスメ・美容
- 水・土: キッチン・生活雑貨
- 日: 週次まとめ or 一番反応が良かったジャンルの深掘り投稿

## テスト期間と絞り込み基準
- 期間: 6週間（開始日は依頼者がROOMアカウント作成・投稿開始できる日に合わせて確定）
- 絞り込み判断に使う指標: [03_kpi_framework.md](03_kpi_framework.md) のジャンル別集計
- 6週目末に「フォロワー増加率」「投稿あたり平均いいね数」「クリック率（可能な範囲で）」の3指標を比較し、
  上位1〜2ジャンルに投稿頻度を寄せる（完全に切り捨てず、比率を変える形が望ましい）

## 未確定事項（進めながら確認）
- Room上で実際にクリック数・流入元が取得できる範囲（管理画面の仕様は要確認）
- 各ジャンルでの適正な投稿本数比率は、実データが集まってから再調整
