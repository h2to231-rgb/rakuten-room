# KPIフレームワーク

アカウントがゼロからのスタートのため、初期の目標値はすべて「仮説」として置き、
実データが入り次第この数値を補正する（初回投稿から2週間後に見直し予定）。

## 追跡する指標

| 指標 | 取得元 | 頻度 |
|---|---|---|
| フォロワー数 | ROOMプロフィール画面 | 日次 |
| 投稿あたりいいね数 | 各投稿ページ | 投稿ごと |
| 投稿完了率（毎日1本を守れたか） | 手動記録 | 日次 |
| クリック数（可能な範囲） | ROOM管理画面 / 楽天アフィリエイト管理画面 | 週次 |
| 成果件数・成果報酬額 | 楽天アフィリエイト管理画面 | 週次 |
| ジャンル別の上記指標 | 上記を[02_genre_test_plan.md](02_genre_test_plan.md)のジャンルタグで集計 | 週次 |

## 初期目標値（仮説・6週間テスト期間）

| 週 | フォロワー数（累計） | 投稿あたり平均いいね | 投稿完了率 |
|---|---|---|---|
| 1週目 | +5〜10 | 1〜3 | 100%（7/7投稿） |
| 2週目 | +10〜20 | 2〜4 | 100% |
| 4週目 | +30〜50 | 3〜6 | ≥90% |
| 6週目 | +60〜100 | 5〜10 | ≥90% |

成果報酬（売上）は母数が小さいうちはブレが大きいため、6週目までは「発生した/しなかった」の有無と
ジャンル別の偏りを見る程度にとどめ、具体的な金額目標は3ヶ月目以降に設定する。

## 週次レビューのやり方（人間 + AI）
1. 依頼者が上表の実績値をこのファイルの下の「実績ログ」に追記（もしくはAgentに数値を伝えて記録させる）
2. AI（分析Agent、フェーズ6で構築）が実績と目標のギャップ・ジャンル別の傾向をまとめる
3. 翌週の投稿ローテーション比率・企画方針を調整
