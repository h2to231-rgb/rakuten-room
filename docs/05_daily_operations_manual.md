# 毎日の運用手順書

このプロジェクトフォルダ（`rakuten_room`）で、以下を毎日行ってください。所要時間目安10〜15分。
投稿の最終実行は楽天ROOM利用規約により必ず人間（あなた）が行う必要があります。

## 毎日やること

### ステップ1: 投稿候補を生成する
```bash
python run_daily.py
```
今日のジャンル（曜日で自動判定）でリサーチ→ドラフト生成→コンプラチェックが走り、
`reports/YYYY-MM-DD.md` が作られます。

### ステップ2: 候補を確認する
`reports/YYYY-MM-DD.md` を開いて、案を1つ選びます。選ぶ前に必ず確認:
- [ ] 商品が本当にそのジャンルに合っているか（目視で確認。まれに無関係な商品が混ざることがある）
- [ ] コンプラチェックが「✅ 問題なし」になっているか（⚠️の場合は文面を確認・修正）
- [ ] 文章に不自然な誇張表現・断定的な効果表現がないか
- [ ] 価格が実際の商品ページと大きくズレていないか（変動することがあるため）

気に入らない部分があれば `content_drafts/` 配下の該当`.txt`を直接編集してOKです。

### ステップ3: 楽天ROOMに投稿する（人間が行う）
1. 選んだ案のアフィリエイトリンクをコピー
2. 楽天ROOMアプリ/サイトで新規投稿を作成
3. 商品を検索してひも付け（またはURLから直接追加）
4. 生成された紹介文をコピペ（必要なら微調整）
5. 投稿を実行

### ステップ4: その日の実績を記録する
投稿した日のうちか翌朝、ROOMのプロフィール画面でフォロワー数と投稿のいいね数を確認して記録します。
```bash
python analytics/analyze.py log --date YYYY-MM-DD --genre <gadget|beauty|kitchen> \
    --followers <フォロワー累計数> --posts 1 --likes <いいね数>
```
クリック数・成果件数・報酬額（`--clicks` `--conversions` `--revenue`）は、
楽天アフィリエイト管理画面から週1回程度まとめて追記で構いません。

## 週1回やること

### 振り返りレポートを見る
```bash
python analytics/analyze.py report
```
[docs/03_kpi_framework.md](03_kpi_framework.md)の目標値と比較した週次サマリー、
ジャンル別の反応の違い、ローテーション調整の提案が `reports/analysis_latest.md` に出力されます。
提案が出たら、[docs/02_genre_test_plan.md](02_genre_test_plan.md)のジャンル配分の見直しを検討してください。

## トラブルシューティング
- `run_daily.py`実行時にAPIエラーが出た場合、`403`はアクセス権限やドメイン設定、`429`はリクエスト過多（少し待って再実行）が原因であることが多いです。頻発する場合は共有してください。
- 候補が0件で終わる場合、その日のジャンルで条件に合う商品が少なかった可能性があります。`--hits`オプションを増やして再実行できます（例: `python run_daily.py --top 5`）。
